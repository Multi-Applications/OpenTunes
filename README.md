# OpenTunes

Web radio player with Radio-Browser API built with TypeScript and TailWind CSS

## Infomation

[![Website](https://img.shields.io/badge/OpenTunes%20website-blue?style=flat\&link=https://open-tunes.pages.dev)](https://open-tunes.pages.dev)
[![License: MIT](https://img.shields.io/badge/license-MIT-green?style=flat)](LICENSE)

## Features

* Discover radio stations worldwide via the Radio-Browser API
* Filter by country and genre
* Search stations by name or tags
* Save favorites and add custom stations
* Dark / Light mode and multi-language UI (EN, DE, NL, IT, FR)
